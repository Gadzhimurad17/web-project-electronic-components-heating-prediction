# Git Contribution Guidelines

## 1. Branch Naming Convention

В проекте используются основные ветки для лабораторных работ и дополнительные рабочие ветки для разработки, тестирования и исправления ошибок.

### 1.1. Main Branches


| Branch  | Description                                        |
| ------- | -------------------------------------------------- |
| `main`  | Основная ветка проекта         |
| `lab-1` | Первая лабораторная работа |
| `lab-2` | Вторая лабораторная работа |
| `lab-3` | Третья лабораторная работа |

### 1.2. Working Branches

Для выполнения отдельных задач используются ветки с соответствующими префиксами.


| Prefix    | Description                                           | Example                    |
| --------- | ----------------------------------------------------- | -------------------------- |
| `[dev]`   | Разработка функциональности | `[dev] lab-1-feature`      |
| `[tests]` | Написание и изменение тестов | `[tests] lab-1-unit-tests` |
| `[fix]`   | Исправление ошибок                   | `[fix] lab-1-validation`   |
| `[style]` | Форматирование кода                 | `[style] lab-2-formatting` |

### 1.3. Branch Naming Rules

1. Использовать английский язык.
2. Основные ветки должны называться `main`, `lab-1`, `lab-2` и `lab-3`.
3. Рабочие ветки должны начинаться с соответствующего префикса в квадратных скобках.
4. После префикса указывать лабораторную работу и краткое описание задачи.
5. Использовать дефисы для разделения слов в описании.
6. Название ветки должно отражать её назначение.
7. Не использовать слишком общие названия, например `[dev] new` или `[fix] changes`.
8. Для каждой отдельной задачи создавать отдельную рабочую ветку.

Examples:

```text
main
lab1
lab2
lab3

[dev] lab-1-feature
[dev] lab-2-data-processing
[dev] lab-3-api
[tests] lab-1-unit-tests
[tests] lab-2-integration-tests
[fix] lab-1-validation
[docs] lab-2-readme
[refactor] lab-3-code-cleanup
```
